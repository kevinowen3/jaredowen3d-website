# Web presence research: where Jared Owen is referenced online

Compiled 2026-09-12 from a wide web sweep (roughly 180 searches across five parallel
research passes: press coverage, podcasts and talks, educational and reference uses,
profile pages and platforms, and non-English coverage). The goal was to find anything the
site could link to and anything about Jared's online presence that the site gets wrong.

**Verification key.** *Fetched* means the page was loaded and confirmed to be about this
Jared Owen (there are unrelated namesakes: an AFL footballer, a pastor, a Redbrain CEO, an
artist named Jared Owens). *Seen only* means the URL came back in search results verbatim
but the site blocks automated fetching (Boing Boing, The Awesomer, Adafruit, BlenderNation,
Born To Engineer, LinkedIn, X, Reddit all do), so open it in a browser before linking.

`facebook.com/jaredowenanimations`, is the one linked from the Shorts channel, the old Wix
site (Wayback snapshot 2025-01-20), and the social-media contractor's portfolio.

| facebook.com/JaredOwen3d (currently linked) | 117,180 |

Jared's main YouTube About tab links the smaller one, so confirm with him which he
considers primary before switching.

**"DevCon Talk" label.** The About page calls the 2019 talk "DevCon Talk". YouTube titles
it "Becoming A Youtuber With 3D Animation - 2019 Clearwater Talk", uploaded on Jared's own
channel. Probably the Clearwater Analytics developer conference in Boise. A second upload
of the same talk (`SkTT38bjyLk`, presumably the organiser's copy) is now private; do not
link it.
